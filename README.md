# GSF Consulting Internationale

Bienvenue sur le dépôt GitHub du site web de **GSF Consulting Internationale**. Ce site est hébergé via GitHub Pages.

## Description
GSF Consulting Internationale transforme le droit par l’intelligence artificielle. De l’expertise juridique **OHADA** et anti-blanchiment de capitaux, aux solutions de recouvrement augmentées par l’IA, nous réinventons le conseil pour l’Afrique.

## Services Principaux
* ⭐ **Agent IA de Recouvrement** : Automatisez vos créances impayées. Analyse de risque, scoring prédictif et relances intelligentes conformes au droit OHADA.
* ⚖️ **Conseil Juridique & Financier** : Expertise reconnue auprès de la CEDEAO, l’AFD et la Francophonie. Négociation internationale et gestion des risques.
* 🛡️ **Conformité RegTech** : Plateforme SaaS pour Fintechs et Banques : cartographie des obligations (BCEAO, BEAC) et veille réglementaire automatisée.
